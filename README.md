# לילה טוב מתחיל בהיכרות – רותם סגל

המדריך הדיגיטלי של רותם סגל, מדריכת הורים ויועצת שינה, לכנס בייבילנד.

**האתר:** https://itaylevi1302.github.io/rotem-guide/
**סטטיסטיקות:** https://rotemsegal.goatcounter.com

## מה יש כאן

| נתיב | מה זה |
|---|---|
| `index.html` | המדריך הדיגיטלי (מותאם לטלפון, כפתורי וואטסאפ, שתי דלתות כניסה) |
| `guide.pdf` | המדריך המקורי כ־PDF מכווץ |
| `img/` | תמונות ואיורים מתוך המדריך |
| `qr/` | קודי QR. **להדפסה: `qr-rotem-guide-logo.png`** (עם הלוגו, נספר כסריקה) |
| `print/` | חומרי דפוס: קובצי PDF מוכנים, ו־HTML שמהם נוצרו |

## חומרי דפוס (`print/`)

| קובץ | גודל |
|---|---|
| `sign-a3.pdf` | שלט דוכן A3 |
| `postcard-a6.pdf` | גלויה למקרר A6, דו־צדדית |
| `game-cards-a5.pdf` | משחק "זהי את הסימן", 4 כרטיסים דו־צדדיים A5 |
| `gift-voucher.pdf` | שובר "מתנה ללידה", 21×9.9 ס"מ |
| `gift-sign-a5.pdf` | שלט "מחפשים מתנה ללידה?" A5 |
| `magnet-7x10.pdf` / `magnet-7x10-bleed.pdf` | מגנט 7×10 ס"מ, בלי ועם 3 מ"מ שוליים לחיתוך |

## חשוב

- לא לשנות את שם הריפו ולא למחוק אותו: ה־QR המודפס מוביל לכתובת הזו.
- עדכון טקסט ב־`index.html` ודחיפה ל־`main` מעדכנים את האתר תוך כמה דקות. ה־QR לא משתנה.
